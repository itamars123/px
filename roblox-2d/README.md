# 🎮 משחק פלטפורמה דו-ממדי (2D) ברובלוקס

משחק בסגנון "צד" (כמו משחקי קפיצות קלאסיים): המצלמה מהצד, זזים רק ימינה ושמאלה וקופצים.

## מה יש במשחק
- 🟩 פלטפורמות לקפוץ עליהן ובורות ליפול אליהם
- 🟥 קוצים אדומים: נגיעה = מוות
- 🪙 מטבעות זהב (חוזרים אחרי 10 שניות)
- 🏳️ 3 נקודות שמירה: אחרי מוות חוזרים לנקודה האחרונה
- 🟪 מעלית שעולה ויורדת
- 🏁 קו סיום: +50 מטבעות וחזרה להתחלה
- 📱 כפתורים על המסך לטלפון/טאבלט

## מקשים
| פעולה | מקלדת |
|---|---|
| שמאלה | A או ⬅️ |
| ימינה | D או ➡️ |
| קפיצה | רווח, W או ⬆️ |

## איך מכניסים לרובלוקס סטודיו (5 דקות)
1. פותחים **Roblox Studio** ← **New** ← **Baseplate**.
2. מוחקים את ה-**Baseplate** מתוך **Workspace** (לחיצה ימנית ← Delete).
3. ב-**Explorer**, לחיצה ימנית על **ServerScriptService** ← **Insert Object** ← **Script**.
   משנים את השם ל-`Game2DServer`, מוחקים את מה שכתוב בו, ומדביקים את כל התוכן של `Game2DServer.server.lua`.
4. פותחים את **StarterPlayer**, לחיצה ימנית על **StarterPlayerScripts** ← **Insert Object** ← **LocalScript**.
   משנים את השם ל-`Controller2D` ומדביקים את התוכן של `Controller2D.client.lua`.
5. לוחצים **Play** ▶️ ומשחקים!

## רוצים לשנות את השלב?
בראש הקובץ `Game2DServer` יש רשימות שקל לערוך:
- `PLATFORMS`: כל שורה היא `{x של הקצה השמאלי, גובה, רוחב, צבע}`
- `SPIKES`: `{x, גובה}` של קוצים
- `COINS`: `{x, y}` של מטבעות
- `CHECKPOINTS`: נקודות שמירה
- `FINISH`: איפה קו הסיום

💡 טיפ: קפיצה רגילה מגיעה לגובה של ~7 ולמרחק של ~15. לכן כדאי לשמור על רווחים של עד 10 ועל עליות של עד 5.
