# JOJO 2D

אנימציה קצרה בסגנון קרטון (12.5 שניות, 720x720, 30fps), מצוירת ב-Canvas 2D.

עלילה: בחור עם כוס קפה ליד חלון → מפלצת ורודה ומפחידה מופיעה מאחוריו → "don't panic, that's just your STAND" → היא הופכת לחמודה → שורת סטנדים → כרטיס שם "BUBBLEGUM".

- `jojo-2d.mp4` – הסרטון המוכן (כולל פסקול סינתטי).
- `index.html` – האנימציה עצמה. להפעלה חיה: `python3 -m http.server` בתיקייה הזו ולפתוח `http://localhost:8000`.
