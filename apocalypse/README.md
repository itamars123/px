# Last Light

A top-down zombie apocalypse survival shooter. Open `index.html` in a browser; no build step or dependencies.

- **Move:** WASD / arrow keys · **Aim & shoot:** mouse (hold to fire)
- **Weapons:** 1 / 2 / 3, Q or mouse wheel · **Reload:** R · **Grenade:** G or right-click · **Pause:** P / Esc
- **Touch:** left stick moves, right stick aims and fires; SW / G / R buttons on the right

Survive each night of zombie waves (walkers, runners, brutes, acid spitters, and a boss every 5th night).
Collect scrap from the dead and spend it at dawn on healing, armor, damage, speed, reload upgrades,
a shotgun, an SMG, ammo and grenades. Your best run is saved in the browser.
