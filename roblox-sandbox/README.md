# ⛏️ Block Diggers – משחק ארגז חול דו-ממדי ברובלוקס

משחק חפירה ובנייה מהצד, **כולו בפיקסל-ארט** 🟫🟩: עולם שנוצר באקראי, חוצבים בלוקים, אוספים מחצבים, יוצרים כלים, בונים מחסה, ובלילה נלחמים במפלצות.

## 🎨 הכול פיקסלים
- **בלוקים**: לכל בלוק יש טקסטורת פיקסלים 8×8 (דשא, אדמה, אבן, פחם, ברזל, זהב, עץ, עלים, קרשים, לבנים, לפיד)
- **הדמות**: גיבור פיקסלים (10×16) במקום האווטאר, שמסתובב ימינה/שמאלה ו"הולך" עם 2 פריימים של רגליים
- **מפלצות**: מפלצת פיקסלים סגולה עם עיניים צהובות
- **שמיים**: שמש ירח ועננים מרובעים, כוכבים בלילה, וצבע שמיים שמשתנה בשקיעה ובזריחה
- **ממשק**: גופן פיקסלים (Arcade), מסגרות שחורות מרובעות ואייקונים מפוקסלים בסרגל
- **מצלמה**: עדשה צרה ממרחק, כך שהעולם נראה שטוח לגמרי, כמו משחק דו-ממדי אמיתי

## מה יש במשחק
- 🌍 **עולם אקראי** (100×55 בלוקים): גבעות דשא, אדמה, אבן, מערות ועצים, וכל משחק יוצא עולם אחר
- ⛏️ **חציבה**: מחזיקים לחיצה על בלוק עד שהוא נשבר. אבן קשה יותר מאדמה
- 💎 **מחצבים**: פחם, ברזל (עמוק יותר) וזהב (הכי עמוק, וצריך מכוש ברזל כדי לחצוב אותו!)
- 🧱 **בנייה**: אדמה, אבן, קרשים, לבני אבן ולפידים (שמאירים בחושך)
- 🔨 **יצירה** (מקש C):
  | מה מקבלים | מה צריך |
  |---|---|
  | 4 קרשים | 1 עץ |
  | 2 לבני אבן | 2 אבן |
  | 4 לפידים | 1 עץ + 1 פחם |
  | מכוש ברזל (חוצב מהר פי 1.8, וגם זהב) | 5 ברזל + 3 עץ |
  | מכוש זהב (חוצב מהר פי 2.8) | 5 זהב + 3 עץ |
  | חרב ברזל (נזק 30 במקום 12) | 4 ברזל + 1 עץ |
- 🌙 **יום ולילה**: יום שלם נמשך 6 דקות. בלילה יוצאות מפלצות סגולות שרודפות אחריך וקופצות מעל קירות. מנצחים אותן בלחיצה עליהן ומקבלים 3 מטבעות. בבוקר הן נעלמות
- 📱 תומך בטלפון: כפתורי תנועה וכפתור ⛏️/🧱 להחלפה בין חציבה לבנייה

## מקשים

| בנייה | לחיצה ימנית |
| בחירת בלוק | 1-5 או גלגלת העכבר |
| תפריט יצירה | C |

## איך מכניסים לרובלוקס סטודיו
1. פותחים **Roblox Studio** ← **New** ← **Baseplate**, ומוחקים את ה-**Baseplate** וה-**SpawnLocation** מתוך Workspace.
2. **ReplicatedStorage** ← לחיצה ימנית ← Insert Object ← **ModuleScript** (פעמיים):
   - אחד בשם `BlockData` ← מדביקים את `BlockData.lua`
   - אחד בשם `PixelArt` ← מדביקים את `PixelArt.lua`
3. **ServerScriptService** ← Insert Object ← **Script**, ומדביקים את התוכן של `SandboxServer.server.lua`.
4. **StarterPlayer ← StarterPlayerScripts** ← Insert Object ← **LocalScript**, ומדביקים את התוכן של `SandboxClient.client.lua`.
5. לוחצים **Play** ▶️

> ⚠️ השמות `BlockData` ו-`PixelArt` חייבים להיות מדויקים, אחרת הסקריפטים לא ימצאו אותם.

## טיפים לשינויים
- גודל העולם: `WIDTH` / `HEIGHT` ב-`BlockData` (עולם גדול יותר = יותר כבד)
- אורך היום: `DAY_LENGTH` ב-`SandboxServer`
- כמה מפלצות: `MAX_ENEMIES`, `ENEMY_HEALTH`, `ENEMY_DAMAGE`
- בלוק חדש: מוסיפים שורה ל-`BlockData.Blocks`, ואם רוצים שאפשר יהיה לבנות איתו, גם ל-`Placeable`

## לצייר פיקסלים בעצמך
ב-`PixelArt.lua` כל ציור הוא רשימה של שורות טקסט. כל אות היא צבע מה-`palette`, ונקודה (`.`) היא צבע הבסיס או שקוף.
למשל, כדי לשנות את צבע החולצה של הגיבור, משנים את `c` ו-`C` ב-`PixelArt.Hero.palette`.
